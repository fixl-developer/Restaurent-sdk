## 2. SmartDine SDK — Architecture Discussion

### Business Model Decided
- **Product:** SmartDine as an open-core platform (like Supabase)
- **Open core:** Self-hostable engine developers can run on their own infra
- **Hosted SaaS:** SmartDine-hosted cloud with API keys
- **Target customer:** Restaurant chains with in-house dev teams (e.g. Haldiram's, Barbeque Nation)
- **Pricing:** Per restaurant subscription
- **SDK type:** Thin API wrapper (Option A) — developer builds their own UI
- **Distribution:** Separate npm packages, separate GitHub repo

### SDK Package Structure
```
@smartdine/types    — shared TypeScript types (no logic)
@smartdine/core     — HttpClient + RealtimeClient (Socket.IO) + SmartDineClient
@smartdine/menu     — menu.get(), menu.search(), menu.getItem()
@smartdine/orders   — orders.placeDineIn(), placeWindow(), get(), findByNumber(), track(), sendRequest(), submitFeedback()
@smartdine/kds      — kds.getActiveOrders(), updateItemStatus(), subscribe()
@smartdine/otp      — otp.request(), otp.verify()
```

### Developer Usage
```ts
// Self-hosted
const client = new SmartDineClient({ baseUrl: 'https://api.myrestaurant.com' })

// SmartDine cloud
const client = new SmartDineClient({ apiKey: 'sk_live_xxx' })

// Same API either way
const menu = new MenuClient(client.http)
const orders = new OrdersClient(client.http, client.realtime)

const { categories } = await menu.get({ slug: 'my-restaurant' })
const order = await orders.placeDineIn({ items: [...] })
const unsubscribe = orders.track({
  orderId: order.id,
  onStatusChange: (status) => console.log('Status:', status),
})
```
